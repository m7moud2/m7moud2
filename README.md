> **Practical Modular Observability & Monitoring Pipeline**

- **Modular Stacks:** Independent Compose setups for **Nginx Web Server** monitoring (`stub_status` + Nginx Exporter) and **WordPress + MySQL 8.0** monitoring (`mysqld-exporter`).
- **Prometheus & Alertmanager:** Custom scrape configurations, alert rules for server downtime, and maintenance silencing workflows.
- **Grafana Auto-Provisioning:** Automated datasource provisioning (`http://prometheus:9090`) and pre-configured JSON dashboard layouts.
- **CI/CD & Testing:** Automated GitHub Actions validation workflows, shell health-check scripts, and chaos test suites.
